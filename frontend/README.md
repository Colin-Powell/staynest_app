# StayNest Flutter Frontend (scaffold)

This folder contains a scaffolded Flutter frontend with placeholder screens corresponding to the React `src/components` files.

Next steps:
- Port data and types from `src/data.ts` and `src/types.ts` into Dart (`lib/data.dart`, `lib/models/`).
- Implement UI for each screen and wire navigation.
- Add assets and platform setup (Android/iOS/web) if you want to run the app.

To run (after you have Flutter installed):

```bash
cd flutter_frontend
flutter pub get
flutter run
```
