StayNest landing page

Files:
- index.html — basic landing page using Tailwind CDN
- app.js — minimal JS for download buttons and modal

To preview locally:

```bash
# from repository root
cd landing
# use Python simple HTTP server
python -m http.server 8000
# then open http://localhost:8000
```

Replace the placeholder APK/iOS links in `app.js` with your real hosting URLs or App Store/TestFlight links.
